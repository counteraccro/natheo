### Pour les développeurs

Le site public récupère toutes ses données par l'API v2, construite avec API Platform. Elle répond en JSON-LD avec Hydra, ou en JSON simple, et sa documentation OpenAPI est consultable sur `/api/v2/docs`.

Les appels à l'API, la pagination et la gestion des erreurs sont regroupés dans un socle commun écrit en Vue 3 et TypeScript. Un thème s'appuie sur ce socle et s'occupe uniquement de l'affichage. Natheo-Base, livré sans aucun style, sert de point de départ pour écrire le vôtre.

Nathéo fonctionne avec MySQL, MariaDB ou PostgreSQL. Chaque migration de la base est écrite pour les deux familles, et les tests automatisés tournent sur les deux à chaque modification du code. Le projet est publié sous licence GNU GPL v3.

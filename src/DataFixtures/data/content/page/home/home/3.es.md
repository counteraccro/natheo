### Para los desarrolladores

El sitio público obtiene todos sus datos de la API v2, construida con API Platform. Responde en JSON-LD con Hydra, o en JSON simple, y su documentación OpenAPI se consulta en `/api/v2/docs`.

Las llamadas a la API, la paginación y la gestión de errores están agrupadas en una base común escrita en Vue 3 y TypeScript. Un tema se apoya en esta base y solo se ocupa de la presentación. Natheo-Base, entregado sin ningún estilo, sirve de punto de partida para escribir el suyo.

Nathéo funciona con MySQL, MariaDB o PostgreSQL. Cada migración de la base está escrita para las dos familias, y las pruebas automáticas se ejecutan en ambas con cada cambio en el código. El proyecto se publica bajo la licencia GNU GPL v3.

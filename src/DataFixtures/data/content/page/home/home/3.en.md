### For developers

The public site gets all its data from the API v2, built with API Platform. It answers in JSON-LD with Hydra, or in plain JSON, and its OpenAPI documentation is available on `/api/v2/docs`.

API calls, pagination and error handling are grouped in a shared base written in Vue 3 and TypeScript. A theme relies on this base and only deals with the display. Natheo-Base, shipped without any styling, is the starting point for writing your own.

Nathéo runs on MySQL, MariaDB or PostgreSQL. Every database migration is written for both families, and the automated tests run on both each time the code changes. The project is released under the GNU GPL v3 license.

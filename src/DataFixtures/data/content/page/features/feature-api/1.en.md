## Hydra resources

The API v2 is built with API Platform and served under `/api/v2`. It exposes pages and their blocks, menus, comments, the public site options and the sitemap, along with the account and sessions of the logged-in user.

Responses use JSON-LD with the Hydra vocabulary. A resource linked to another one refers to it by its IRI, for example `/api/v2/pages/12`, and includes a summary of its useful fields. Collections are paginated by 20 items, up to 100 on request with `itemsPerPage`. A client that prefers plain JSON gets it with the `Accept: application/json` header.

Lookups go through exact filters on collections. A page is found from its address with `GET /api/v2/pages?slug=api-v2`, and the menus of a position with the `position` filter.

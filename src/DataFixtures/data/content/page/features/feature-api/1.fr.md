## Des ressources Hydra

L'API v2 est construite avec API Platform et servie sous `/api/v2`. Elle expose les pages et leurs blocs, les menus, les commentaires, les options publiques du site et le plan du site, ainsi que le compte et les sessions de l'utilisateur connecté.

Les réponses sont au format JSON-LD avec le vocabulaire Hydra. Une ressource liée à une autre la désigne par son IRI, par exemple `/api/v2/pages/12`, et inclut un résumé de ses champs utiles. Les collections sont paginées par 20 éléments, jusqu'à 100 sur demande avec `itemsPerPage`. Un client qui préfère du JSON simple l'obtient avec l'en-tête `Accept: application/json`.

Les recherches passent par des filtres exacts sur les collections. Une page se retrouve à partir de son adresse avec `GET /api/v2/pages?slug=api-v2`, et les menus d'une position avec le filtre `position`.

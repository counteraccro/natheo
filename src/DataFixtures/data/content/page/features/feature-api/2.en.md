## Authentication

The API v2 offers two ways to authenticate.

The first one uses an API token. It is created in the administration, from the "API tokens" menu, with a read, write or admin role. This is what you use to connect an external application or an import script to Nathéo. The public site works the same way, with a token created during installation.

The second one is for actions made on behalf of a user, for example when they post a comment with their account. The user opens a session by sending their login and password to `/user_sessions`. In return, they get an access token valid for 15 minutes and a refresh token used to obtain a new one. The session carries the rights of the API token that opened it. A user can list their open sessions through the API and close each one separately.

In both cases, the token is sent in the `Authorization: Bearer` header. The "Open the API?" system option cuts off all access at once.

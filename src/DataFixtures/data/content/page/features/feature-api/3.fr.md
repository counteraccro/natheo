## Le site public en est le premier client

Le site que vous lisez est une application Vue 3 qui récupère toutes ses données par l'API v2. Les pages, les menus, les commentaires et le pied de page passent par les mêmes ressources que celles d'une application externe. Même le compteur de lectures en est une, avec un appel à `POST /page_reads` à chaque affichage de page.

Quand un membre de l'équipe est connecté à l'administration, le site reçoit aussi un access token à son nom. Il s'en sert pour afficher le lien « Modifier cette page » et pour modérer les commentaires sous la page. L'API ne sert jamais un brouillon. Pour la prévisualisation, le serveur prépare le brouillon au même format qu'une réponse de l'API, et le thème l'affiche donc exactement comme la version publiée.

Cette organisation sert aussi de test permanent. Une ressource incomplète ou une erreur mal formée se voient tout de suite sur le site.

## Recursos Hydra

La API v2 está construida con API Platform y se sirve en `/api/v2`. Expone las páginas y sus bloques, los menús, los comentarios, las opciones públicas del sitio y el mapa del sitio, además de la cuenta y las sesiones del usuario conectado.

Las respuestas están en formato JSON-LD con el vocabulario Hydra. Un recurso vinculado a otro lo designa por su IRI, por ejemplo `/api/v2/pages/12`, e incluye un resumen de sus campos útiles. Las colecciones se paginan de 20 en 20 elementos, hasta 100 si se pide con `itemsPerPage`. Un cliente que prefiera JSON simple lo obtiene con la cabecera `Accept: application/json`.

Las búsquedas se hacen con filtros exactos sobre las colecciones. Una página se encuentra a partir de su dirección con `GET /api/v2/pages?slug=api-v2`, y los menús de una posición con el filtro `position`.

## Documented with OpenAPI

Each operation describes its parameters, its response format and the errors it can return. The documentation is generated from the code and available with Swagger UI on `/api/v2/docs`, where you can try the calls with your own token. It stays available as long as the API is open.

Errors follow the `application/problem+json` format. Their title and detail are translated into the language of the request, and a validation error lists the fields involved.

The old API v1 remains available under `/api/v1` until Nathéo 3.0. It no longer gets new features, and its responses carry the `Deprecation` and `Link` headers to point the clients still using it to the v2.

## L'authentification

L'API v2 propose deux façons de s'authentifier.

La première passe par un token d'API. Il se crée dans l'administration, depuis le menu « Tokens API », avec un rôle de lecture, d'écriture ou d'administration. C'est la solution à utiliser pour connecter une application externe ou un script d'import à Nathéo. Le site public fonctionne de la même façon, avec un token créé à l'installation.

La seconde sert quand une action est faite au nom d'un utilisateur, par exemple quand il poste un commentaire avec son compte. Il ouvre une session en envoyant son identifiant et son mot de passe à `/user_sessions`. En retour, il reçoit un access token valable 15 minutes et un refresh token qui permet d'en obtenir un nouveau. La session reprend les droits du token d'API qui l'a ouverte. Ses sessions ouvertes sont consultables par l'API, et chacune peut être fermée séparément.

Dans les deux cas, le jeton s'envoie dans l'en-tête `Authorization: Bearer`. L'option système « Ouvrir l'API ? » coupe tous les accès d'un coup.

## The public site is its first client

The site you are reading is a Vue 3 application that gets all its data from the API v2. Pages, menus, comments and the footer go through the same resources an external application would use. Even the read counter is one of them, with a call to `POST /page_reads` each time a page is displayed.

When a team member is logged in to the administration, the site also receives an access token in their name. It uses it to show the "Edit this page" link and to moderate comments under the page. The API never serves a draft. For previews, the server builds the draft in the same format as an API response, so the theme displays it exactly like the published version.

This setup also works as a permanent test. An incomplete resource or a badly formed error shows up on the site right away.

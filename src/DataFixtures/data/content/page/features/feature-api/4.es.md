## Documentada con OpenAPI

Cada operación describe sus parámetros, su formato de respuesta y los errores que puede devolver. La documentación se genera a partir del código y se consulta con Swagger UI en `/api/v2/docs`, donde se pueden probar las llamadas con su propio token. Está disponible mientras la API esté abierta.

Los errores siguen el formato `application/problem+json`. Su título y su detalle se traducen al idioma de la petición, y un error de validación lista los campos afectados.

La antigua API v1 sigue disponible en `/api/v1` hasta Nathéo 3.0. Ya no recibe novedades, y sus respuestas llevan las cabeceras `Deprecation` y `Link` para indicar la v2 a los clientes que todavía la usan.

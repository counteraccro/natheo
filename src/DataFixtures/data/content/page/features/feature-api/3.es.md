## El sitio público es su primer cliente

El sitio que está leyendo es una aplicación Vue 3 que obtiene todos sus datos de la API v2. Las páginas, los menús, los comentarios y el pie de página pasan por los mismos recursos que usaría una aplicación externa. Incluso el contador de lecturas es uno de ellos, con una llamada a `POST /page_reads` cada vez que se muestra una página.

Cuando un miembro del equipo está conectado a la administración, el sitio recibe también un access token a su nombre. Lo usa para mostrar el enlace «Editar esta página» y para moderar los comentarios debajo de la página. La API nunca sirve un borrador. Para la previsualización, el servidor prepara el borrador en el mismo formato que una respuesta de la API, así que el tema lo muestra exactamente igual que la versión publicada.

Esta organización sirve también de prueba permanente. Un recurso incompleto o un error mal formado se notan enseguida en el sitio.

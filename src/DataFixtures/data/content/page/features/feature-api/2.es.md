## La autenticación

La API v2 ofrece dos formas de autenticarse.

La primera usa un token de API. Se crea en la administración, desde el menú «Tokens API», con un rol de lectura, de escritura o de administración. Es la opción para conectar una aplicación externa o un script de importación a Nathéo. El sitio público funciona igual, con un token creado durante la instalación.

La segunda sirve cuando una acción se hace en nombre de un usuario, por ejemplo cuando publica un comentario con su cuenta. El usuario abre una sesión enviando su identificador y su contraseña a `/user_sessions`. A cambio recibe un access token válido durante 15 minutos y un refresh token que permite obtener uno nuevo. La sesión tiene los permisos del token de API que la abrió. El usuario puede consultar sus sesiones abiertas por la API y cerrar cada una por separado.

En ambos casos, el token se envía en la cabecera `Authorization: Bearer`. La opción de sistema «¿Abrir la API?» corta todos los accesos de una vez.

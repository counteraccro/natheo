## Documentée en OpenAPI

Chaque opération décrit ses paramètres, son format de réponse et les erreurs qu'elle peut renvoyer. La documentation est générée à partir du code et consultable avec Swagger UI sur `/api/v2/docs`, où l'on peut essayer les appels avec son propre token. Elle reste accessible tant que l'API est ouverte.

Les erreurs suivent le format `application/problem+json`. Leur titre et leur détail sont traduits dans la langue de la requête, et une erreur de validation liste les champs en cause.

L'ancienne API v1 reste disponible sous `/api/v1` jusqu'à Nathéo 3.0. Elle ne reçoit plus de nouveautés, et ses réponses portent les en-têtes `Deprecation` et `Link` pour signaler la v2 aux clients qui l'utilisent encore.

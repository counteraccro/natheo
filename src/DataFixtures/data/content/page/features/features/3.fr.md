## La technique

Le site public est un client de l'[API v2](/fr/page/api-v2), documentée en OpenAPI. Le thème du site se change dans les options système, sans toucher aux contenus.

Nathéo tourne sur MySQL, MariaDB ou PostgreSQL. Les tests automatisés, plus de 600, sont lancés sur les deux familles de bases à chaque modification, et la construction de l'interface vérifie les types TypeScript.

Le code est publié sous licence GNU GPL v3 sur GitHub, où se trouvent aussi la [feuille de route](/fr/page/feuille-de-route) et les issues ouvertes.

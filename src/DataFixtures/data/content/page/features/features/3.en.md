## Under the hood

The public site is a client of the [API v2](/en/page/api-v2), documented with OpenAPI. The site theme is changed in the system options, without touching the content.

Nathéo runs on MySQL, MariaDB or PostgreSQL. The automated tests, more than 600 of them, run on both database families each time the code changes, and the interface build checks the TypeScript types.

The code is released under the GNU GPL v3 license on GitHub, where you will also find the [roadmap](/en/page/roadmap) and the open issues.

## Eight layouts and three block types

The layout sets the number of blocks and where they go. It ranges from a single full-width block to four blocks on two rows, with two or three columns and stacked blocks in between. The home page of this site places a full-width block above two columns. The [Permissions and validation](/en/page/permissions-and-validation) page stacks three blocks.

Each block gets one of these contents.

- Markdown text, with headings, lists, tables, links and images.
- A FAQ saved in Nathéo, shown as questions that expand.
- The paginated list of the latest pages of a category, as on the [blog](/en/page/blog).

This page uses the two-column layout. On a narrow screen, the columns move one below the other.

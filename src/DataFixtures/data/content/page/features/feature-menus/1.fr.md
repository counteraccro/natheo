## Onze types de menus

| Position | Types |
|---|---|
| En-tête | menu déroulant, méga menu de 1 à 4 colonnes, barre latérale |
| Côtés | menu déplié, menu en accordéon |
| Pied de page | colonnes, une ligne alignée à droite ou centrée |

Un élément de menu mène à une page du site ou à une adresse externe, dans le même onglet ou un nouveau. Les éléments s'imbriquent et se réordonnent par glisser-déposer.

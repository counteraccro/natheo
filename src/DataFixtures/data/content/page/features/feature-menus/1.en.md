## Eleven menu types

A menu is attached to a position on the page, and each position offers its own display types.

| Position | Types |
|---|---|
| Header | dropdown menu, mega menu with 1 to 4 columns, sidebar |
| Sides | expanded menu, accordion menu |
| Footer | columns, a single row aligned right or centered |

A menu item leads to a page of the site or to an external address, and opens in the same tab or in a new one. Its label is entered in each language. Items can be nested inside each other and reordered by drag and drop in the menu editor.

An item that leads to an unpublished page is not shown on the site, and neither are its sub-items. You can prepare a menu before the pages it contains go live.

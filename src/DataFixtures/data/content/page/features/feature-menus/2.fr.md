## Un menu par défaut, ou un menu par section

Chaque position a un menu par défaut, affiché sur toutes les pages du site. Une page peut le remplacer par un autre menu pour la même position.

Ce site s'en sert pour donner à chaque section sa navigation. Les pages de fonctionnalités, comme celle-ci, ont un méga menu dans l'en-tête. La documentation a son sommaire dans un menu déplié à gauche, et le blog un menu en accordéon à droite. Sur les [mentions légales](/fr/page/mentions-legales), le menu d'en-tête est une barre latérale : ses liens s'ouvrent depuis le bouton en haut à droite de l'écran. Les autres pages gardent le menu par défaut.

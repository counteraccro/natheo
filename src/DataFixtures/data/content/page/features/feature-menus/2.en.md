## A default menu, or one menu per section

Each position has a default menu, shown on every page of the site. A page can replace it with another menu for the same position.

This site uses that to give each section its own navigation. Feature pages, like this one, have a mega menu in the header. The documentation has its table of contents in an expanded menu on the left, and the blog an accordion menu on the right. On the [legal notice](/en/page/legal-notice), the header menu is a sidebar, whose links open from the button at the top right of the screen. Other pages keep the default menu.

## Three languages, from content to interface

Pages, blocks, menus, FAQs and tags are translated into **French**, **English** and **Spanish**. Each language has its own page addresses: this page is called `multilingue` in French and `multilingual` in English.

The site's language switcher keeps the current page. On the API side, the language comes from the `locale` parameter or the `Accept-Language` header.

## A translated and checked interface

The administration is fully translated into all three languages, and each user picks their own. Tests check that no translation is missing, and labels can be edited from the back office without touching the code.

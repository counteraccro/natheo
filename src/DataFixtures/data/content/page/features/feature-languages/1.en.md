## Content in three languages

Pages, their blocks, menus, FAQs and tags are entered in French, English and Spanish. Each language has its own addresses. This page is called `multilingue` in French, `multilingual` in English and `multilingue` in Spanish, under `/fr`, `/en` or `/es`. The title, description and keywords meant for search engines are translated too, and the sitemap lists the versions of each page in the other languages.

The language selector, at the top of the site and in the footer, leads to the home page in the chosen language. The default language offered to visitors is set in the system options.

The API v2 follows the same logic. The content language is chosen with the `locale` parameter or the `Accept-Language` header, and the response gives the language served in the `Content-Language` header.

## The administration in everyone's language

The administration is translated into the three languages, and each user picks theirs in their options. Two people can work on the same page, one in French and the other in Spanish.

Interface labels are edited from the "Translations" tool, without touching the code. Automated tests check that no label is missing in any of the languages.

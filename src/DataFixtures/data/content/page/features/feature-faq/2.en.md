## A FAQ in any page

A FAQ does not belong to any page. To display it, you add a FAQ block to a page and pick the FAQ you want. The same FAQ can appear on several pages, and a change made in the administration shows everywhere at once.

This page is an example. It combines two text blocks and, below them, the FAQ about the API. The [Frequently asked questions](/en/faq/frequently-asked-questions) page shows another FAQ, about Nathéo in general.

As long as a FAQ is used in a page, it cannot be deleted. Nathéo lists the pages involved, so that no empty block is left on the site.

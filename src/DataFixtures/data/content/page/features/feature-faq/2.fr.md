## Une FAQ dans n'importe quelle page

Une FAQ ne dépend d'aucune page. Pour l'afficher, on ajoute un bloc de type FAQ dans une page et on choisit la FAQ voulue. La même FAQ peut ainsi apparaître sur plusieurs pages, et une modification faite dans l'administration se voit partout à la fois.

Cette page en est un exemple. Elle combine deux blocs de texte et, en dessous, la FAQ sur l'API. La page [Questions fréquentes](/fr/faq/questions-frequentes) affiche une autre FAQ, consacrée à Nathéo en général.

Tant qu'une FAQ est utilisée dans une page, elle ne peut pas être supprimée. Nathéo indique les pages concernées, pour éviter de laisser un bloc vide sur le site.

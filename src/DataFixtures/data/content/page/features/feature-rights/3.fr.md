## La modération des commentaires

Les commentaires s'ouvrent ou se ferment pour tout le site dans les options système, puis page par page. Chaque page indique aussi si un nouveau commentaire est publié tout de suite ou s'il attend une validation. L'option « Forcer la validation des nouveaux commentaires » impose la validation partout, quel que soit le réglage de la page.

Un commentaire en attente reste à sa place sur le site, avec un message qui indique qu'il sera publié après validation. Un commentaire modéré est remplacé par un message pour les visiteurs. Le modérateur peut écrire la raison de la modération, que seuls les membres de l'équipe voient.

La modération se fait dans l'écran « Commentaires » de l'administration, un par un ou par lot. Un administrateur connecté peut aussi valider ou modérer un commentaire directement sous la page, sur le site.

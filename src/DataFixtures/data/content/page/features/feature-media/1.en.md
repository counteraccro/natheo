## Images and documents in one place

The media library accepts JPEG, PNG, GIF and WebP images, as well as PDF, Word, Excel and PowerPoint documents. You add a file by dropping it into the upload window, with a name and a description. Nathéo checks the extension and the real type of the file before saving it.

Files are sorted into folders, which can hold subfolders. By default, these folders are virtual and all files stay in the same place on the server. A system option creates a real folder on disk for each folder of the media library. Files are shown in a grid, with a thumbnail for images, or in a list, and can be sorted by name, date or type.

A deleted file first goes to the trash. It can be restored from there until it is deleted for good.

Images from the media library are also used as page header images. The ones on this site are screenshots of Nathéo, stored in the "en-tetes" and "captures" folders. The screenshots inserted in the pages come from the same place.

## SQL portable

Las actualizaciones de datos escritas a mano plantean otro problema. Algunas sintaxis existen en una sola plataforma: `UPDATE … JOIN` y `REGEXP` en MySQL, `UPDATE … FROM` y el operador `~` en PostgreSQL. En ese caso, la consulta se escribe dos veces, una en cada archivo.

Las palabras reservadas también requieren atención. La tabla de los usuarios se llama `user`, una palabra reservada. Está entre comillas invertidas en el mapeo de Doctrine, que Doctrine convierte en comillas dobles en PostgreSQL. En el SQL escrito a mano, el nombre se protege con `quoteSingleIdentifier()`, que elige los caracteres correctos para la base conectada.

Las pruebas lo comprueban todo. En cada pull request, GitHub Actions ejecuta toda la batería de PHPUnit dos veces, en MySQL 8.4 y en PostgreSQL 16, y las dos deben pasar antes del merge.

## Portable SQL

Hand-written data updates raise another problem. Some syntax exists on a single platform: `UPDATE … JOIN` and `REGEXP` on MySQL, `UPDATE … FROM` and the `~` operator on PostgreSQL. In that case, the query is written twice, once in each file.

Reserved words need care too. The users table is called `user`, a reserved word. It is wrapped in backticks in the Doctrine mapping, which Doctrine turns into double quotes on PostgreSQL. In hand-written SQL, the name is protected with `quoteSingleIdentifier()`, which picks the right characters for the connected database.

Tests check all of this. On every pull request, GitHub Actions runs the whole PHPUnit suite twice, on MySQL 8.4 and on PostgreSQL 16, and both must pass before the merge.

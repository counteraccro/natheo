## Du SQL portable

Les mises à jour de données écrites à la main posent un autre problème. Certaines syntaxes existent sur une seule plateforme : `UPDATE … JOIN` et `REGEXP` côté MySQL, `UPDATE … FROM` et l'opérateur `~` côté PostgreSQL. Dans ce cas, la requête est écrite deux fois, une dans chaque fichier.

Les noms réservés demandent aussi de l'attention. La table des utilisateurs s'appelle `user`, un mot réservé. Elle est entourée de backticks dans le mapping Doctrine, que Doctrine traduit en guillemets doubles sur PostgreSQL. Dans le SQL écrit à la main, le nom est protégé avec `quoteSingleIdentifier()`, qui choisit les bons caractères pour la base connectée.

Les tests vérifient le tout. À chaque pull request, GitHub Actions lance toute la suite PHPUnit deux fois, sur MySQL 8.4 et sur PostgreSQL 16, et les deux doivent passer avant le merge.

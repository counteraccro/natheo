2.0 rebuilt the foundations. 2.1 tackles what you do every day with a CMS: write, review, publish and display.

## Write safely

Editing a live page no longer touches it: changes go into a **draft**, previewed on the site and then published in one click. With the "Page validation" option, contributors submit their pages and an administrator approves them, from a dedicated dashboard block.

## An API v2

The API is rewritten with **API Platform**: JSON-LD / Hydra, OpenAPI documentation, `problem+json` errors, and user sessions with renewal. The v1 remains available, deprecated, until 3.0.

## A new public site

The public site starts over on the API v2: a base shared by all themes, the **Natheo-Base** starter theme and a new **Natheo-Horizon**, the one you are reading, with a real dark mode and WCAG 2.2 AA accessibility as the reference.

All the details are in the [changelog](https://github.com/counteraccro/natheo/blob/master/CHANGELOG.md).

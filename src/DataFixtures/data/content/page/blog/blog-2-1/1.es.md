La 2.0 reconstruyó los cimientos. La 2.1 se ocupa de lo que se hace cada día con un CMS: escribir, revisar, publicar y mostrar.

## Escribir sin riesgo

Modificar una página publicada ya no la toca: los cambios van a un **borrador**, que se previsualiza en el sitio y se publica con un clic. Con la opción «Validación de páginas», los colaboradores envían sus páginas y un administrador las valida, desde un bloque dedicado del panel de control.

## Una API v2

La API se reescribe con **API Platform**: JSON-LD / Hydra, documentación OpenAPI, errores `problem+json` y sesiones de usuario con renovación. La v1 sigue disponible, obsoleta, hasta la 3.0.

## Un nuevo sitio público

El sitio público empieza de cero sobre la API v2: una base común a todos los temas, el tema modelo **Natheo-Base** y un nuevo **Natheo-Horizon**, el que estás leyendo, con un verdadero modo oscuro y la accesibilidad WCAG 2.2 AA como referencia.

Todos los detalles están en el [registro de cambios](https://github.com/counteraccro/natheo/blob/master/CHANGELOG.md).

Nathéo 2.1 ya está disponible. Después de una 2.0 dedicada a la administración, esta versión se ocupa de la publicación de las páginas y del sitio público.

## Borradores y validación

Cuando modifica una página que ya está publicada, sus cambios van a un borrador. La versión publicada sigue en el sitio, y puede previsualizar el borrador en el sitio antes de publicarlo. Con la opción «Validación de páginas», un colaborador envía su página a un administrador, que la encuentra en el bloque «Páginas por validar» del panel de control y la valida o la rechaza indicando un motivo.

## La API v2

La API se reescribió con API Platform y responde en `/api/v2`, en JSON-LD con Hydra o en JSON simple. Está documentada con OpenAPI en `/api/v2/docs`. Un usuario puede abrir una sesión por la API, con un access token de 15 minutos y un refresh token para renovarlo. La API v1 sigue disponible hasta la 3.0, pero ya no recibe novedades.

## El sitio público y sus temas

El sitio público se reescribió para leer todos sus datos de la API v2. Los temas se apoyan en una base común y se eligen en las opciones de sistema. Hay tres: Natheo-Base, sin estilo, para empezar el suyo, la nueva versión de Natheo-Horizon, que está leyendo ahora mismo, y StormFront.

## En la administración

Los carruseles de imágenes llegan como nuevo tipo de contenido, que se coloca en un bloque de página. El editor de texto pasa a ser visual sin dejar de guardar Markdown, y puede hacer que una IA revise un texto si configura un proveedor. La mediateca incorpora una búsqueda, la selección de varios archivos y el almacenamiento en un servidor externo.

El detalle está en el [registro de cambios](https://github.com/counteraccro/natheo/blob/master/CHANGELOG.md), y lo que viene después en la [hoja de ruta](/es/page/hoja-de-ruta).

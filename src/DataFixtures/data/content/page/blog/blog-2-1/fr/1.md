La 2.0 a reconstruit les fondations. La 2.1 s'attaque à ce qu'on fait chaque jour avec un CMS : écrire, relire, publier, et afficher.

## Écrire sans risque

Modifier une page en ligne ne la touche plus : les changements vont dans un **brouillon**, prévisualisé sur le site puis publié d'un clic. Avec l'option « Validation des pages », les contributeurs soumettent leurs pages et un administrateur les valide, depuis un bloc dédié du tableau de bord.

## Une API v2

L'API est réécrite avec **API Platform** : JSON-LD / Hydra, documentation OpenAPI, erreurs `problem+json`, et des sessions utilisateur avec renouvellement. La v1 reste disponible, dépréciée, jusqu'à la 3.0.

## Un nouveau site public

Le site public repart de zéro sur l'API v2 : un socle commun à tous les thèmes, le thème modèle **Natheo-Base** et un nouveau **Natheo-Horizon**, celui que vous lisez, avec un vrai mode sombre et l'accessibilité WCAG 2.2 AA pour référence.

Tout le détail est dans le [journal des modifications](https://github.com/counteraccro/natheo/blob/master/CHANGELOG.md).

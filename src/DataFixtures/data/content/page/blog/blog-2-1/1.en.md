Nathéo 2.1 is out. After a 2.0 devoted to the administration, this release deals with page publishing and the public site.

## Drafts and validation

When you edit a page that is already live, your changes go into a draft. The published version stays on the site, and you can preview the draft on the site before publishing it. With the "Page validation" option, a contributor submits their page to an administrator, who finds it in the "Pages to review" block of the dashboard and approves it or rejects it with a reason.

## The API v2

The API was rewritten with API Platform and answers under `/api/v2`, in JSON-LD with Hydra or in plain JSON. It is documented with OpenAPI on `/api/v2/docs`. A user can open a session through the API, with a 15-minute access token and a refresh token to renew it. The API v1 remains available until 3.0, but no longer gets new features.

## The public site and its themes

The public site was rewritten to read all its data from the API v2. Themes rely on a shared base and are chosen in the system options. There are three of them: Natheo-Base, without styling, to start your own, the new version of Natheo-Horizon, which you are reading right now, and StormFront.

## In the administration

Image carousels arrive as a new content type, to place in a page block. The text editor becomes visual while still saving Markdown, and can have a text reviewed by an AI if you configure a provider. The media library gains search, multiple file selection and storage on an external server.

The details are in the [changelog](https://github.com/counteraccro/natheo/blob/master/CHANGELOG.md), and what comes next on the [roadmap](/en/page/roadmap).

Nathéo 2.0 was released on **7 November 2026**. It is a major technical update, needed to secure the future of the CMS.

## What changes

- **A back office redesigned** from A to Z, in Tailwind CSS 4, with dark mode and colour themes.
- **Symfony 8.1 and Vite**: modernised PHP code and a faster front end, written in TypeScript.
- **MySQL / MariaDB and PostgreSQL**, with dedicated migrations for each platform.
- **A fully translated interface** in French, English and Spanish.
- **A security audit** of every module: escaped grids, CSRF protection, per-content permissions.

## Before you update

The database schema is new: there is no automatic migration from V1, a fresh installation is required. PHP 8.4 is now the minimum.

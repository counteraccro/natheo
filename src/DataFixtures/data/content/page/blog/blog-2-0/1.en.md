Nathéo 2.0 came out on November 7, 2026. This release reworks the administration screen by screen and changes the database schema.

## A new administration

Bootstrap was replaced by Tailwind CSS 4. Every screen was redone, from the login page to the page editor, with a dark mode and several color themes. The Vue 3 components are written in TypeScript, and the dashboard shows statistics and blocks that each user can configure.

The interface is translated into English and Spanish. Tests check that every label exists in the three languages.

## PostgreSQL

Nathéo now runs on PostgreSQL, in addition to MySQL and MariaDB. Schema updates go through Doctrine migrations, written for each of the two families. The post [One database, two platforms](/en/page/one-database-two-platforms) explains how.

## A security audit

Before the release, every module was audited: content, system, tools, API and public site. The administration grids escape entered values, actions sent in the background check a CSRF token, and permissions are checked for each piece of content. The fixed vulnerabilities are described in two security advisories published on GitHub.

## Before upgrading

The database schema changed too much for a 1.0 installation to be upgraded automatically. You need a fresh 2.0 installation, then to bring your content over. Version 2.0 requires PHP 8.4, and at least MySQL 8.2, MariaDB 10.11 or PostgreSQL 15.2.

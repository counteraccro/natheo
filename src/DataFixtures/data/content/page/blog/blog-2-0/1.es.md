Nathéo 2.0 salió el 7 de noviembre de 2026. Esta versión rehace la administración pantalla por pantalla y cambia el esquema de la base de datos.

## Una nueva administración

Bootstrap se sustituyó por Tailwind CSS 4. Se rehicieron todas las pantallas, desde el inicio de sesión hasta el editor de páginas, con un modo oscuro y varios temas de color. Los componentes Vue 3 están escritos en TypeScript, y el panel de control muestra estadísticas y bloques que cada usuario puede configurar.

La interfaz está traducida al inglés y al español. Unas pruebas comprueban que cada texto existe en los tres idiomas.

## PostgreSQL

Nathéo funciona ahora con PostgreSQL, además de MySQL y MariaDB. Las actualizaciones del esquema pasan por migraciones Doctrine, escritas para cada una de las dos familias. El artículo [Una base, dos plataformas](/es/page/una-base-dos-plataformas) explica cómo.

## Una auditoría de seguridad

Antes de la salida, se auditó cada módulo: contenidos, sistema, herramientas, API y sitio público. Las tablas de la administración escapan los valores introducidos, las acciones enviadas en segundo plano comprueban un token CSRF y los permisos se controlan contenido por contenido. Los fallos corregidos están descritos en dos avisos de seguridad publicados en GitHub.

## Antes de actualizar

El esquema de la base cambió demasiado para que una instalación 1.0 se actualice automáticamente. Hay que instalar la 2.0 desde cero y después recuperar el contenido. La 2.0 requiere PHP 8.4, y como mínimo MySQL 8.2, MariaDB 10.11 o PostgreSQL 15.2.

[Descargar la 2.0](https://github.com/counteraccro/natheo/releases/tag/v2.0.0)

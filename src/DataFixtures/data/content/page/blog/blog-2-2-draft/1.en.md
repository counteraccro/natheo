*Post submitted for an administrator's approval.*

Version 2.1 is out, and work on what comes next has started. The goal is to make every action of the administration available through the API v2, with the same permissions as in the interface.

Today, the API v2 is mostly used for reading. It lets you post a comment, count a read or open a session, but a page or a menu is still edited in the administration. Version 2.2 is meant to add write resources for content: pages, FAQs, menus, tags, comments and carousels. The media library will follow, with file uploads and folder management.

During this step, the current administration keeps working as before. An external application, an import script or a mobile app will be able to write to Nathéo without going through it. Editing a page from the public site, for a logged-in team member, is also part of this project.

The breakdown is not settled yet. If you have a specific need, come and talk about it on [Discord](https://discord.gg/CgcMCcbmaR).

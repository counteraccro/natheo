*Artículo enviado para la validación de un administrador.*

La 2.1 ya ha salido, y el trabajo sobre lo siguiente ha empezado. El objetivo es que todas las acciones de la administración estén disponibles por la API v2, con los mismos permisos que en la interfaz.

Hoy, la API v2 sirve sobre todo para leer. Permite publicar un comentario, contar una lectura o abrir una sesión, pero una página o un menú todavía se modifican en la administración. La 2.2 debe añadir los recursos de escritura para los contenidos: páginas, FAQ, menús, etiquetas, comentarios y carruseles. La mediateca vendrá después, con la subida de archivos y la gestión de las carpetas.

Durante esta etapa, la administración actual sigue funcionando como antes. Una aplicación externa, un script de importación o una aplicación móvil podrán escribir en Nathéo sin pasar por ella. La edición de una página desde el sitio público, para un miembro del equipo conectado, también está prevista en este proyecto.

El reparto del trabajo todavía no está decidido. Si tiene una necesidad concreta, venga a hablarlo en [Discord](https://discord.gg/CgcMCcbmaR).

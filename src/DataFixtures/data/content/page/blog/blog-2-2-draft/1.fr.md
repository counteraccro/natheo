*Article soumis à la validation d'un administrateur.*

La 2.1 est sortie, et le travail sur la suite a commencé. L'objectif est de rendre toutes les actions de l'administration disponibles par l'API v2, avec les mêmes droits que dans l'interface.

Aujourd'hui, l'API v2 sert surtout à lire. Elle permet de poster un commentaire, de compter une lecture ou d'ouvrir une session, mais une page ou un menu se modifient encore dans l'administration. La 2.2 doit ajouter les ressources d'écriture pour les contenus : pages, FAQ, menus, tags, commentaires et carrousels. La médiathèque suivra, avec l'envoi de fichiers et la gestion des dossiers.

Pendant cette étape, l'administration actuelle continue de fonctionner comme avant. Une application externe, un script d'import ou une application mobile pourront écrire dans Nathéo sans passer par elle. La modification d'une page depuis le site public, pour un membre de l'équipe connecté, est aussi prévue dans ce chantier.

Le découpage n'est pas encore arrêté. Si vous avez un besoin précis, venez en parler sur le [Discord](https://discord.gg/CgcMCcbmaR).

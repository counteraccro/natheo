The first stable release of Nathéo came out on October 7, 2025, after two betas.

## Two betas before 1.0

1.0.0-beta.1, published in June 2025, was the first public release. It already covered the core of a CMS: pages and their preview, menus, FAQs, tags, comments and the media library. The administration managed users, site options, translations, logs and emails, and offered an SQL manager. The API v1, protected by tokens, served pages, menus, comments and options.

Beta 2, in September, added the first public site, with the Natheo-Horizon theme. It displayed the header and footer, menus, the breadcrumb, page content and comments, and generated the sitemap.

## What 1.0 added

The stable release mostly changed the tooling. The front end moved from Webpack Encore to Vite, the code was formatted with Prettier, and Symfony was updated to 7.3. Two bugs were also fixed, in the editor window when a page held several editors and in sending a test email.

A year later, 2.0 rebuilt the administration from the ground up.

## Obtenir un token

Créez un token d'API dans **Système › Tokens API**, avec le rôle voulu (lecture, écriture ou administration), et envoyez-le dans l'en-tête `Authorization`.

## Lire une page

```bash
curl -H "Authorization: Bearer <token>" \
     -H "Accept-Language: fr" \
     "https://votre-site.fr/api/v2/pages?slug=accueil"
```

La réponse est une collection Hydra de 0 ou 1 page, avec ses blocs, ses menus et ses tags.

## Explorer

La liste des ressources, de leurs paramètres et de leurs erreurs est sur `/api/v2/docs`. Vous venez de la v1 ? Le [guide de migration](https://counteraccro.github.io/natheo.doc/Docs/API/migration_v2.html) détaille les changements.

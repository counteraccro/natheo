## Get a token

Create an API token in **System › API tokens**, with the role you need (read, write or admin), and send it in the `Authorization` header.

## Read a page

```bash
curl -H "Authorization: Bearer <token>" \
     -H "Accept-Language: en" \
     "https://your-site.com/api/v2/pages?slug=home"
```

The response is a Hydra collection of 0 or 1 page, with its blocks, menus and tags.

## Obtener un token

Crea un token de API en **Sistema › Tokens API**, con el rol que necesites (lectura, escritura o administración), y envíalo en la cabecera `Authorization`.

## Leer una página

```bash
curl -H "Authorization: Bearer <token>" \
     -H "Accept-Language: es" \
     "https://tu-sitio.es/api/v2/pages?slug=inicio"
```

La respuesta es una colección Hydra de 0 o 1 página, con sus bloques, sus menús y sus etiquetas.

## Explorar

La lista de recursos, sus parámetros y sus errores está en `/api/v2/docs`. ¿Vienes de la v1? La [guía de migración](https://counteraccro.github.io/natheo.doc/Docs/API/migration_v2.html) detalla los cambios.

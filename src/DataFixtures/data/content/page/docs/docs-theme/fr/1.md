## Un thème ne fait qu'afficher

Tous les thèmes partagent un **socle** : les types des ressources de l'API v2, un client et des composables Vue (`usePage`, `usePageBlocks`, `useMenus`, `useComments`…). Un thème n'appelle jamais l'API lui-même, il reçoit les données de ces composables et les met en forme.

## Les étapes

1. Ajoutez un cas à l'enum `App\Enum\Front\Template` et sa valeur dans l'option `OS_THEME_FRONT_SITE`.
2. Déclarez son entrée Vite `front_<theme>` dans `vite.config.mts`.
3. Créez `templates/front/<theme>/index.html.twig`, qui monte le composant `Front/<Theme>/App`.
4. Écrivez ses composants dans `assets/vue/Components/Front/<Theme>/` : blocs, menus, commentaires.

Partez de **Natheo-Base**, qui affiche tout en HTML sémantique, sans design : chaque disposition, chaque bloc et chaque type de menu y sont déjà rendus.

## A theme only displays

All themes share a **base**: the types of the API v2 resources, a client and Vue composables (`usePage`, `usePageBlocks`, `useMenus`, `useComments`…). A theme never calls the API itself: it receives data from these composables and lays it out.

## The steps

1. Add a case to the `App\Enum\Front\Template` enum and its value to the `OS_THEME_FRONT_SITE` option.
2. Declare its `front_<theme>` Vite entry in `vite.config.mts`.
3. Create `templates/front/<theme>/index.html.twig`, which mounts the `Front/<Theme>/App` component.
4. Write its components in `assets/vue/Components/Front/<Theme>/`: blocks, menus, comments.

Start from **Natheo-Base**, which renders everything in semantic HTML without design: every layout, block and menu type is already there.

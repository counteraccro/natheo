## Le socle et les thèmes

Tous les thèmes du site public reposent sur un socle commun. Il contient les types TypeScript des ressources de l'API v2, un client qui gère l'authentification, la pagination et les erreurs, et des composables Vue comme `usePage`, `usePageBlocks`, `useMenus` ou `useComments`. Un thème n'appelle jamais l'API directement. Ses composants récupèrent les données par ces composables et s'occupent de les afficher.

## L'architecture

Le socle est partagé par tous les thèmes. Chaque thème ajoute ses propres fichiers, ici pour un thème `my_theme`.

```text
assets/
├── ts/Front/Api/                       types des ressources (socle)
├── vue/Composables/Front/              client de l'API et composables (socle)
├── front_my_theme.ts                   entrée Vite du thème
├── styles/app_front_my_theme.css       styles du thème
├── vue/controllers/Front/MyTheme/
│   └── App.vue                         composant racine
└── vue/Components/Front/MyTheme/       en-tête, blocs, menus, commentaires…
templates/front/my_theme/
├── index.html.twig                     monte Front/MyTheme/App
└── close.html.twig                     page affichée quand le site est fermé
```

## Déclarer le thème

Le thème s'ajoute à l'enum `App\Enum\Front\Template` et à la liste de l'option `OS_THEME_FRONT_SITE`, dans `config/cms/options_system.yaml`.

```php
case MY_THEME = 'my_theme';
```

```yaml
list_value: 'natheo_horizon:Natheo-Horizon|natheo_storm:FrontStorm|natheo_base:Natheo-Base|my_theme:Mon thème'
```

Son entrée Vite, déclarée dans `vite.config.mts` sous le nom `front_my_theme`, charge ses styles et ses composants.

```ts
import './styles/app_front_my_theme.css';
import { startVueControllers } from './bootstrap';

startVueControllers(import.meta.glob('./vue/controllers/Front/MyTheme/**/*.vue'));
```

## Écrire les composants

Le composant racine reçoit les props préparées par le serveur et crée le contexte du site avec `createFrontContext()`. Les autres composables le retrouvent ensuite tout seuls.

```vue
<script setup lang="ts">
import { createFrontContext } from '@/vue/Composables/Front/useFrontContext';
import { usePage } from '@/vue/Composables/Front/usePage';
import type { FrontThemeProps } from '@/ts/Front/FrontProps.type';

const props = defineProps<FrontThemeProps>();
createFrontContext(props);
const { data: page, loading } = usePage();
</script>
```

Pour les blocs, `usePageBlocks` reçoit un composant par type de bloc et renvoie la liste des blocs de la page, chacun avec sa largeur (`full`, `half` ou `third`). Le thème choisit les classes qui correspondent à ces largeurs.

```ts
const { blocks } = usePageBlocks(page, { text: BlockText, faq: BlockFaq, listing: BlockListing });
```

`useMenus(page)` fonctionne de la même façon pour les menus. Il les range par position, et `layoutOf(menu)` donne leur type d'affichage (`dropdown`, `mega`, `sidebar`, `accordion`…).

Le plus simple est de partir d'une copie de Natheo-Base, qui affiche toutes les dispositions, tous les types de blocs et tous les menus en HTML sémantique, sans aucun style. Le thème apparaît ensuite dans l'option « Thème de votre site ».

## The base and the themes

All public site themes rely on a shared base. It holds the TypeScript types of the API v2 resources, a client that handles authentication, pagination and errors, and Vue composables such as `usePage`, `usePageBlocks`, `useMenus` or `useComments`. A theme never calls the API directly. Its components get the data through these composables and take care of displaying it.

## The architecture

The base is shared by all themes. Each theme adds its own files, here for a `my_theme` theme.

```text
assets/
├── ts/Front/Api/                       resource types (base)
├── vue/Composables/Front/              API client and composables (base)
├── front_my_theme.ts                   Vite entry of the theme
├── styles/app_front_my_theme.css       theme styles
├── vue/controllers/Front/MyTheme/
│   └── App.vue                         root component
└── vue/Components/Front/MyTheme/       header, blocks, menus, comments…
templates/front/my_theme/
├── index.html.twig                     mounts Front/MyTheme/App
└── close.html.twig                     page shown when the site is closed
```

## Declaring the theme

The theme is added to the `App\Enum\Front\Template` enum and to the list of the `OS_THEME_FRONT_SITE` option, in `config/cms/options_system.yaml`.

```php
case MY_THEME = 'my_theme';
```

```yaml
list_value: 'natheo_horizon:Natheo-Horizon|natheo_storm:FrontStorm|natheo_base:Natheo-Base|my_theme:My theme'
```

Its Vite entry, declared in `vite.config.mts` under the name `front_my_theme`, loads its styles and its components.

```ts
import './styles/app_front_my_theme.css';
import { startVueControllers } from './bootstrap';

startVueControllers(import.meta.glob('./vue/controllers/Front/MyTheme/**/*.vue'));
```

## Writing the components

The root component receives the props prepared by the server and creates the site context with `createFrontContext()`. The other composables then find it on their own.

```vue
<script setup lang="ts">
import { createFrontContext } from '@/vue/Composables/Front/useFrontContext';
import { usePage } from '@/vue/Composables/Front/usePage';
import type { FrontThemeProps } from '@/ts/Front/FrontProps.type';

const props = defineProps<FrontThemeProps>();
createFrontContext(props);
const { data: page, loading } = usePage();
</script>
```

For blocks, `usePageBlocks` receives one component per block type and returns the list of the page blocks, each with its width (`full`, `half` or `third`). The theme picks the classes that match these widths.

```ts
const { blocks } = usePageBlocks(page, { text: BlockText, faq: BlockFaq, listing: BlockListing });
```

`useMenus(page)` works the same way for menus. It sorts them by position, and `layoutOf(menu)` gives their display type (`dropdown`, `mega`, `sidebar`, `accordion`…).

The easiest way is to start from a copy of Natheo-Base, which displays every layout, every block type and every menu in semantic HTML, without any styling. The theme then appears in the "Theme of your site" option.

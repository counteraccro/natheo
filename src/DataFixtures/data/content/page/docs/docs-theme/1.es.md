## La base y los temas

Todos los temas del sitio público se apoyan en una base común. Contiene los tipos TypeScript de los recursos de la API v2, un cliente que gestiona la autenticación, la paginación y los errores, y composables Vue como `usePage`, `usePageBlocks`, `useMenus` o `useComments`. Un tema nunca llama directamente a la API. Sus componentes obtienen los datos con estos composables y se ocupan de mostrarlos.

## La arquitectura

La base la comparten todos los temas. Cada tema añade sus propios archivos, aquí para un tema `my_theme`.

```text
assets/
├── ts/Front/Api/                       tipos de los recursos (base)
├── vue/Composables/Front/              cliente de la API y composables (base)
├── front_my_theme.ts                   entrada Vite del tema
├── styles/app_front_my_theme.css       estilos del tema
├── vue/controllers/Front/MyTheme/
│   └── App.vue                         componente raíz
└── vue/Components/Front/MyTheme/       cabecera, bloques, menús, comentarios…
templates/front/my_theme/
├── index.html.twig                     monta Front/MyTheme/App
└── close.html.twig                     página mostrada cuando el sitio está cerrado
```

## Declarar el tema

El tema se añade al enum `App\Enum\Front\Template` y a la lista de la opción `OS_THEME_FRONT_SITE`, en `config/cms/options_system.yaml`.

```php
case MY_THEME = 'my_theme';
```

```yaml
list_value: 'natheo_horizon:Natheo-Horizon|natheo_storm:FrontStorm|natheo_base:Natheo-Base|my_theme:Mi tema'
```

Su entrada Vite, declarada en `vite.config.mts` con el nombre `front_my_theme`, carga sus estilos y sus componentes.

```ts
import './styles/app_front_my_theme.css';
import { startVueControllers } from './bootstrap';

startVueControllers(import.meta.glob('./vue/controllers/Front/MyTheme/**/*.vue'));
```

## Escribir los componentes

El componente raíz recibe las props preparadas por el servidor y crea el contexto del sitio con `createFrontContext()`. Los demás composables lo encuentran después por sí solos.

```vue
<script setup lang="ts">
import { createFrontContext } from '@/vue/Composables/Front/useFrontContext';
import { usePage } from '@/vue/Composables/Front/usePage';
import type { FrontThemeProps } from '@/ts/Front/FrontProps.type';

const props = defineProps<FrontThemeProps>();
createFrontContext(props);
const { data: page, loading } = usePage();
</script>
```

Para los bloques, `usePageBlocks` recibe un componente por tipo de bloque y devuelve la lista de los bloques de la página, cada uno con su anchura (`full`, `half` o `third`). El tema elige las clases que corresponden a esas anchuras.

```ts
const { blocks } = usePageBlocks(page, { text: BlockText, faq: BlockFaq, listing: BlockListing });
```

`useMenus(page)` funciona igual para los menús. Los ordena por posición, y `layoutOf(menu)` da su tipo de presentación (`dropdown`, `mega`, `sidebar`, `accordion`…).

Lo más sencillo es partir de una copia de Natheo-Base, que muestra todas las disposiciones, todos los tipos de bloques y todos los menús en HTML semántico, sin ningún estilo. El tema aparece después en la opción «Tema de su sitio».

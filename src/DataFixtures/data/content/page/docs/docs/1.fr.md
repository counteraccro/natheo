## Bien démarrer avec Nathéo

Ces quatre guides accompagnent les premiers pas avec Nathéo. Le premier installe le CMS sur votre machine, le deuxième passe en revue les réglages à faire ensuite. Les deux derniers s'adressent aux développeurs, pour créer un thème du site public ou utiliser l'API v2 depuis une autre application.

Le menu à gauche donne accès à chaque guide. C'est un menu de côté propre à la documentation, qui remplace le menu par défaut sur ces pages.

La documentation complète, avec l'installation en production, la configuration de la base de données et la migration depuis l'API v1, se trouve sur [natheo.doc](https://counteraccro.github.io/natheo.doc/).

## Primeros pasos con Nathéo

Estas cuatro guías acompañan los primeros pasos con Nathéo. La primera instala el CMS en su equipo, la segunda repasa los ajustes que hay que hacer después. Las dos últimas están pensadas para los desarrolladores, para crear un tema del sitio público o usar la API v2 desde otra aplicación.

El menú de la izquierda da acceso a cada guía. Es un menú lateral propio de la documentación, que sustituye al menú por defecto en estas páginas.

La documentación completa, con la instalación en producción, la configuración de la base de datos y la migración desde la API v1, está en [natheo.doc](https://counteraccro.github.io/natheo.doc/).

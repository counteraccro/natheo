## Getting started with Nathéo

These four guides cover the first steps with Nathéo. The first one installs the CMS on your machine, the second one goes through the settings to make next. The last two are for developers, to create a theme for the public site or to use the API v2 from another application.

The menu on the left leads to each guide. It is a side menu specific to the documentation, which replaces the default menu on these pages.

The full documentation, with production installation, database configuration and migration from the API v1, is available on [natheo.doc](https://counteraccro.github.io/natheo.doc/).

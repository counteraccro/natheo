## Requirements

- PHP 8.4 or higher, with `ctype`, `iconv`, `pdo`, `pdo_mysql` (or `pdo_pgsql`), `json` and `mbstring`
- Composer 2.8 and Yarn 1.22
- MySQL 8.2, MariaDB 10.11 or PostgreSQL 15.2

## Install

```bash
git clone https://github.com/counteraccro/natheo.git
cd natheo
composer install
cp .env .env.local
```

Set `DATABASE_URL` and `NATHEO_SCHEMA` in `.env.local`, then run the installation, which creates the database, the schema and this demo site:

```bash
php bin/console natheo:install
yarn install
yarn build
```

Point your web server to the `public/` folder: the administration is on `/admin`.

> This procedure is meant for development. For production, follow [the production installation guide](https://counteraccro.github.io/natheo.doc/Docs/Demarrage/installation_prod.html).

## Requirements

Nathéo requires PHP 8.4 or later, with the `ctype`, `iconv`, `pdo`, `json`, `mbstring` and `pdo_mysql` extensions, or `pdo_pgsql` for PostgreSQL. You also need Composer 2.8 and Yarn 1.22. The database can be MySQL 8.2, MariaDB 10.11 or PostgreSQL 15.2, at least.

## Installing for development

Get the code and its dependencies, then create your local configuration file.

```bash
git clone https://github.com/counteraccro/natheo.git
cd natheo
composer install
cp .env .env.local
```

In `.env.local`, set `DATABASE_URL` to the address of your database and `NATHEO_SCHEMA` to its name. The following command creates the database and its schema, loads the demo data and clears the cache. It asks for confirmation before starting, because it deletes the database if it already exists.

```bash
php bin/console natheo:install
yarn install
yarn build
```

Point your web server to the `public/` folder. The demo site is shown at the root, and the administration is on `/en/admin/login`.

## Demo accounts

The demo data creates one account for each administration role, whose password is the email address: `contributeur@natheo.com`, `admin@natheo.com` and `superadmin@natheo.com`. They let you see what each role can do in the administration.

## In production

The `natheo:install` command stops without doing anything in the production environment. Use the installation wizard instead, on `/en/installation`, and follow the [production installation guide](https://counteraccro.github.io/natheo.doc/Docs/Demarrage/installation_prod.html). Also change the passwords of the accounts that were created.

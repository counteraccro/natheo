## Prérequis

- PHP 8.4 ou supérieur, avec `ctype`, `iconv`, `pdo`, `pdo_mysql` (ou `pdo_pgsql`), `json` et `mbstring`
- Composer 2.8 et Yarn 1.22
- MySQL 8.2, MariaDB 10.11 ou PostgreSQL 15.2

## Installer

```bash
git clone https://github.com/counteraccro/natheo.git
cd natheo
composer install
cp .env .env.local
```

Renseignez `DATABASE_URL` et `NATHEO_SCHEMA` dans `.env.local`, puis lancez l'installation, qui crée la base, le schéma et ce site de démonstration :

```bash
php bin/console natheo:install
yarn install
yarn build
```

Faites pointer votre serveur web sur le dossier `public/` : l'administration est sur `/admin`.

> Cette procédure est prévue pour le développement. Pour la production, suivez [le guide d'installation en production](https://counteraccro.github.io/natheo.doc/Docs/Demarrage/installation_prod.html).

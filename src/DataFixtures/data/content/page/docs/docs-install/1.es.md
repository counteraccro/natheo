## Requisitos

Nathéo necesita PHP 8.4 o superior, con las extensiones `ctype`, `iconv`, `pdo`, `json`, `mbstring` y `pdo_mysql`, o `pdo_pgsql` para PostgreSQL. También hacen falta Composer 2.8 y Yarn 1.22. La base de datos puede ser MySQL 8.2, MariaDB 10.11 o PostgreSQL 15.2, como mínimo.

## Instalar en desarrollo

Descargue el código y sus dependencias, y cree después su archivo de configuración local.

```bash
git clone https://github.com/counteraccro/natheo.git
cd natheo
composer install
cp .env .env.local
```

En `.env.local`, indique en `DATABASE_URL` la dirección de su base y en `NATHEO_SCHEMA` su nombre. El comando siguiente crea la base y su esquema, carga los datos de demostración y vacía la caché. Pide una confirmación antes de empezar, porque borra la base si ya existe.

```bash
php bin/console natheo:install
yarn install
yarn build
```

Apunte su servidor web a la carpeta `public/`. El sitio de demostración se muestra en la raíz, y la administración está en `/es/admin/login`.

## Las cuentas de demostración

Los datos de demostración crean una cuenta para cada rol de la administración, cuya contraseña es la dirección de correo: `contributeur@natheo.com`, `admin@natheo.com` y `superadmin@natheo.com`. Permiten ver lo que cada rol puede hacer en la administración.

## En producción

El comando `natheo:install` se detiene sin hacer nada en el entorno de producción. Use en su lugar el asistente de instalación, en `/es/installation`, y siga la [guía de instalación en producción](https://counteraccro.github.io/natheo.doc/Docs/Demarrage/installation_prod.html). Cambie también las contraseñas de las cuentas creadas.

## Requisitos

- PHP 8.4 o superior, con `ctype`, `iconv`, `pdo`, `pdo_mysql` (o `pdo_pgsql`), `json` y `mbstring`
- Composer 2.8 y Yarn 1.22
- MySQL 8.2, MariaDB 10.11 o PostgreSQL 15.2

## Instalar

```bash
git clone https://github.com/counteraccro/natheo.git
cd natheo
composer install
cp .env .env.local
```

Indica `DATABASE_URL` y `NATHEO_SCHEMA` en `.env.local` y lanza la instalación, que crea la base, el esquema y este sitio de demostración:

```bash
php bin/console natheo:install
yarn install
yarn build
```

Apunta tu servidor web a la carpeta `public/`: la administración está en `/admin`.

> Este procedimiento está pensado para desarrollo. Para producción, sigue [la guía de instalación en producción](https://counteraccro.github.io/natheo.doc/Docs/Demarrage/installation_prod.html).

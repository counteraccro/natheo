## Prérequis

Nathéo demande PHP 8.4 ou plus récent, avec les extensions `ctype`, `iconv`, `pdo`, `json`, `mbstring` et `pdo_mysql`, ou `pdo_pgsql` pour PostgreSQL. Il faut aussi Composer 2.8 et Yarn 1.22. La base de données peut être MySQL 8.2, MariaDB 10.11 ou PostgreSQL 15.2, au minimum.

## Installer en développement

Récupérez le code et ses dépendances, puis créez votre fichier de configuration local.

```bash
git clone https://github.com/counteraccro/natheo.git
cd natheo
composer install
cp .env .env.local
```

Dans `.env.local`, renseignez `DATABASE_URL` avec l'adresse de votre base et `NATHEO_SCHEMA` avec son nom. La commande suivante crée la base et son schéma, charge les données de démonstration et vide le cache. Elle demande une confirmation avant de commencer, car elle supprime la base si elle existe déjà.

```bash
php bin/console natheo:install
yarn install
yarn build
```

Faites pointer votre serveur web sur le dossier `public/`. Le site de démonstration s'affiche à la racine, et l'administration se trouve sur `/fr/admin/login`.

## Les comptes de démonstration

Les données de démonstration créent un compte pour chaque rôle de l'administration, dont le mot de passe est l'adresse email : `contributeur@natheo.com`, `admin@natheo.com` et `superadmin@natheo.com`. Ils permettent de voir ce que chaque rôle peut faire dans l'administration.

## En production

La commande `natheo:install` s'arrête sans rien faire en environnement de production. Utilisez plutôt l'assistant d'installation, sur `/fr/installation`, et suivez le [guide d'installation en production](https://counteraccro.github.io/natheo.doc/Docs/Demarrage/installation_prod.html). Changez aussi les mots de passe des comptes créés.

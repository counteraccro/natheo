## Las opciones del sistema

Todo se ajusta desde **Sistema › Opciones del sistema**, sin tocar ningún archivo:

- **Sitio web**: nombre y dirección del sitio, idioma por defecto, tema del sitio público, apertura al público, texto y redes sociales del pie de página.
- **Administración**: validación de páginas, confirmación antes de salir de un formulario, número de elementos por página.
- **Comentarios**: apertura de los comentarios y validación de los nuevos comentarios.
- **API**: apertura de la API y duración de las sesiones de los usuarios.
- Y también: SEO, mediateca, correos, notificaciones y logs.

## La base de datos

MySQL se usa por defecto. Para PostgreSQL, cambia `DATABASE_URL` y activa la extensión `pdo_pgsql`: las migraciones de cada plataforma se cargan automáticamente. Más detalles en [la página de configuración de la base](https://counteraccro.github.io/natheo.doc/Docs/Demarrage/base_de_donnees.html).

## Las tareas asíncronas

Los correos y algunas tareas pasan por una cola de Messenger, que se procesa con:

```bash
php bin/console messenger:consume async
```

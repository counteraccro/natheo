## Les options système

Tout se règle depuis **Système › Options système**, sans toucher aux fichiers :

- **Site web** : nom et adresse du site, langue par défaut, thème du site public, ouverture au public, texte et réseaux sociaux du pied de page.
- **Administration** : validation des pages, confirmation avant de quitter un formulaire, nombre d'éléments par page.
- **Commentaires** : ouverture des commentaires et validation des nouveaux commentaires.
- **API** : ouverture de l'API et durée des sessions des utilisateurs.
- Et aussi : SEO, médiathèque, emails, notifications et logs.

## La base de données

MySQL est utilisé par défaut. Pour PostgreSQL, changez `DATABASE_URL` et activez l'extension `pdo_pgsql` : les migrations de chaque plateforme sont chargées automatiquement. Détails sur [la page de configuration de la base](https://counteraccro.github.io/natheo.doc/Docs/Demarrage/base_de_donnees.html).

## Les tâches asynchrones

Les emails et certaines tâches passent par une file Messenger, à traiter avec :

```bash
php bin/console messenger:consume async
```

## System options

Everything is set from **System › System options**, without touching any file:

- **Website**: site name and address, default language, public site theme, opening to the public, footer text and social networks.
- **Administration**: page validation, confirmation before leaving a form, number of items per page.
- **Comments**: opening comments and approval of new comments.
- **API**: opening the API and user session length.
- And also: SEO, media library, emails, notifications and logs.

## Database

MySQL is used by default. For PostgreSQL, change `DATABASE_URL` and enable the `pdo_pgsql` extension: each platform's migrations are loaded automatically. Details on [the database configuration page](https://counteraccro.github.io/natheo.doc/Docs/Demarrage/base_de_donnees.html).

## Asynchronous tasks

Emails and some tasks go through a Messenger queue, processed with:

```bash
php bin/console messenger:consume async
```

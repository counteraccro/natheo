## Data stored by Nathéo

To write the part about personal data, here is what Nathéo stores.

- A comment keeps its author's name, email address, IP address and browser. Only the name and the text are shown on the site. The other information is used for moderation.
- A user account holds the name, login, email address and password, stored as a hash. Each session opened through the API keeps the IP address, the browser and the login dates.
- Read statistics are counters per page, with no information about visitors.
- In the browser, the public site keeps the light or dark mode choice in local storage. The administration uses a session cookie while the user is logged in.
- A script added in the script system options, in the HEAD tag or at the start or end of the BODY tag, such as an audience measurement tool, can set its own cookies. It then requires the visitor's consent before it loads.

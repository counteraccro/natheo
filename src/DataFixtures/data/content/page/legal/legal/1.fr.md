## Une page à remplacer

Cette page fait partie des données de démonstration de Nathéo. Elle sert aussi d'exemple pour les menus : son menu d'en-tête est une barre latérale, qui s'ouvre avec le bouton en haut à droite de l'écran.

Avant de mettre votre site en ligne, remplacez ce texte par vos propres mentions légales. En France, la loi pour la confiance dans l'économie numérique demande d'indiquer qui édite le site (nom ou raison sociale, adresse et moyen de contact), le nom du directeur de la publication, et le nom, l'adresse et le téléphone de l'hébergeur.

## Les données enregistrées par Nathéo

Pour rédiger la partie sur les données personnelles, voici ce que Nathéo enregistre.

- Un commentaire conserve le nom de son auteur, son adresse email, son adresse IP et le navigateur utilisé. Seuls le nom et le texte sont affichés sur le site. Les autres informations servent à la modération.
- Un compte utilisateur contient le nom, le login, l'adresse email et le mot de passe, enregistré sous forme hachée. Chaque session ouverte par l'API garde l'adresse IP, le navigateur et les dates de connexion.
- Les statistiques de lecture sont des compteurs par page, sans information sur les visiteurs.
- Dans le navigateur, le site public garde le choix du mode clair ou sombre dans le stockage local. L'administration utilise un cookie de session tant que l'utilisateur est connecté.

Quand un compte est supprimé, l'option « Remplacer l'utilisateur supprimé par l'utilisateur fantôme John Doe » rattache ses contenus à un utilisateur anonyme. Indiquez sur cette page combien de temps vous gardez ces données et comment une personne peut y accéder ou demander leur suppression.

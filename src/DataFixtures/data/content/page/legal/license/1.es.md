## Las bibliotecas utilizadas

Nathéo se apoya en proyectos libres que tienen su propia licencia. Symfony, API Platform, Vue, Tailwind CSS y Flowbite se distribuyen bajo la licencia MIT. La fuente Schibsted Grotesk, que usa el tema Natheo-Horizon, está bajo la SIL Open Font License. La lista completa de las dependencias está en los archivos `composer.json` y `package.json` del repositorio.

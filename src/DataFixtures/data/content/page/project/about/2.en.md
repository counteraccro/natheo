## Technical choices

The server is built on Symfony 8.1. Controllers stay short and the logic lives in services, shared by the administration, the API and the public site. A Nathéo controller can be overridden in your project without changing the original code.

Administration pages are rendered by Twig. The interactive parts, such as the page editor, the grids or the media library, are Vue 3 components written in TypeScript and mounted in these pages with Symfony UX. Styling uses Tailwind CSS 4. Dark mode and the color themes of the administration rely on CSS variables.

The public site is a Vue 3 application that gets all its data from the API v2. This API is built with API Platform, which generates the OpenAPI documentation and the Hydra responses from the PHP classes that describe it.

Each database migration is written twice, once for MySQL and MariaDB and once for PostgreSQL. More than 600 PHPUnit tests run on both platforms for every pull request, and the front-end build checks the TypeScript types.

## La historia del proyecto

El desarrollo de Nathéo empezó en febrero de 2023. La primera versión pública, la 1.0.0-beta.1, salió en junio de 2025. Ya gestionaba las páginas, los menús, las FAQ, las etiquetas, los comentarios y la mediateca, y ofrecía una primera API, la v1. La beta siguiente añadió el tema público Natheo-Horizon, y la 1.0 estable llegó el 7 de octubre de 2025, con el paso de Webpack Encore a Vite.

La 2.0, publicada el 7 de noviembre de 2026, rehízo la administración pantalla por pantalla. Bootstrap se sustituyó por Tailwind CSS, la interfaz se tradujo al inglés y al español, y PostgreSQL pasó a ser una base soportada al mismo nivel que MySQL y MariaDB. Antes de la salida, se auditó cada módulo. Los fallos encontrados se corrigieron y se describieron en dos avisos de seguridad publicados en GitHub. El esquema de la base cambió tanto que una instalación 1.0 no se puede actualizar a la 2.0.

La 2.1 se centró en el sitio público. Las páginas ganaron un borrador y una validación, se construyó una API v2 con API Platform y los temas se reescribieron para usarla. La misma versión añadió los carruseles, un editor de texto visual y una mediateca renovada. El sitio que está leyendo funciona con la 2.1.

## Les choix techniques

- **Symfony 8** pour le back, **Vue 3** et **TypeScript** pour les interfaces, **Tailwind CSS** pour le style.
- **API Platform** pour l'API v2, au format JSON-LD / Hydra.
- **MySQL / MariaDB ou PostgreSQL**, au choix.
- Des tests automatisés, lancés sur les deux bases à chaque modification.

## Les choix techniques

Le serveur repose sur Symfony 8.1. Les contrôleurs restent courts et la logique est placée dans des services, partagés entre l'administration, l'API et le site public. Un contrôleur de Nathéo peut être surchargé dans votre projet sans modifier le code d'origine.

Les pages de l'administration sont rendues par Twig. Les parties interactives, comme l'éditeur de page, les grilles ou la médiathèque, sont des composants Vue 3 écrits en TypeScript et montés dans ces pages avec Symfony UX. Le style utilise Tailwind CSS 4. Le mode sombre et les thèmes de couleur de l'administration passent par des variables CSS.

Le site public est une application Vue 3 qui récupère toutes ses données dans l'API v2. Cette API est construite avec API Platform, qui génère la documentation OpenAPI et les réponses au format Hydra à partir des classes PHP qui la décrivent.

Chaque migration de la base est écrite deux fois, une pour MySQL et MariaDB, une pour PostgreSQL. Plus de 600 tests PHPUnit tournent sur les deux plateformes à chaque pull request, et la construction du front vérifie les types TypeScript.

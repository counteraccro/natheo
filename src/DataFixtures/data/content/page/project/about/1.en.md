## The story of the project

Work on Nathéo started in February 2023. The first public release, 1.0.0-beta.1, came out in June 2025. It already handled pages, menus, FAQs, tags, comments and the media library, and offered a first API, the v1. The next beta added the Natheo-Horizon public theme, then the stable 1.0 arrived on October 7, 2025, with the move from Webpack Encore to Vite.

Version 2.0, released on November 7, 2026, reworked the administration screen by screen. Bootstrap was replaced by Tailwind CSS, the interface was translated into English and Spanish, and PostgreSQL became a supported database on the same level as MySQL and MariaDB. Before the release, every module was audited. The vulnerabilities found were fixed, then described in two security advisories published on GitHub. The database schema changed so much that a 1.0 installation cannot be upgraded to 2.0.

Version 2.1 focused on the public site. Pages gained a draft and a validation step, an API v2 was built with API Platform, and the themes were rewritten to use it. The same version added carousels, a visual text editor and a reworked media library. The site you are reading runs on 2.1.

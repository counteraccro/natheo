## L'histoire du projet

Le développement de Nathéo a commencé en février 2023. La première version publique, la 1.0.0-beta.1, est sortie en juin 2025. Elle gérait déjà les pages, les menus, les FAQ, les tags, les commentaires et la médiathèque, et proposait une première API, la v1. La bêta suivante a ajouté le thème public Natheo-Horizon, puis la 1.0 stable est arrivée le 7 octobre 2025, avec le passage de Webpack Encore à Vite.

La 2.0, publiée le 7 novembre 2026, a repris l'administration écran par écran. Bootstrap a été remplacé par Tailwind CSS, l'interface a été traduite en anglais et en espagnol, et PostgreSQL est devenu une base supportée au même titre que MySQL et MariaDB. Avant la sortie, chaque module a été audité. Les failles trouvées ont été corrigées, puis décrites dans deux avis de sécurité publiés sur GitHub. Le schéma de la base a tellement changé qu'une installation 1.0 ne peut pas être mise à jour vers la 2.0.

La 2.1 a porté sur le site public. Les pages ont gagné un brouillon et une validation, une API v2 a été construite avec API Platform, et les thèmes ont été réécrits pour s'en servir. La même version a ajouté les carrousels, un éditeur de texte visuel et une médiathèque revue. Le site que vous lisez tourne sur la 2.1.

## Las decisiones técnicas

El servidor se basa en Symfony 8.1. Los controladores son cortos y la lógica está en servicios, compartidos por la administración, la API y el sitio público. Un controlador de Nathéo se puede sobrescribir en su proyecto sin modificar el código original.

Las páginas de la administración se generan con Twig. Las partes interactivas, como el editor de páginas, las tablas o la mediateca, son componentes Vue 3 escritos en TypeScript y montados en esas páginas con Symfony UX. El estilo usa Tailwind CSS 4. El modo oscuro y los temas de color de la administración funcionan con variables CSS.

El sitio público es una aplicación Vue 3 que obtiene todos sus datos de la API v2. Esta API está construida con API Platform, que genera la documentación OpenAPI y las respuestas en formato Hydra a partir de las clases PHP que la describen.

Cada migración de la base se escribe dos veces, una para MySQL y MariaDB y otra para PostgreSQL. Más de 600 pruebas PHPUnit se ejecutan en las dos plataformas con cada pull request, y la compilación del front comprueba los tipos de TypeScript.

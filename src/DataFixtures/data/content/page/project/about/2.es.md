## Las decisiones técnicas

- **Symfony 8** para el back, **Vue 3** y **TypeScript** para las interfaces, **Tailwind CSS** para el estilo.
- **API Platform** para la API v2, en formato JSON-LD / Hydra.
- **MySQL / MariaDB o PostgreSQL**, a elegir.
- Pruebas automatizadas, lanzadas en las dos bases con cada cambio.

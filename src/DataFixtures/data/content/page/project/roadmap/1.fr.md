## La 2.1, dernière version publiée

La 2.1 était découpée en plusieurs chantiers, chacun suivi dans une Epic sur GitHub. Tous sont terminés.

Une page publiée a maintenant un brouillon, et l'option « Validation des pages » fait relire les pages des contributeurs par un administrateur avant leur publication. L'API v2, construite avec API Platform, expose les pages, les menus, les commentaires, les options du site et les sessions des utilisateurs. Le site public a été réécrit pour passer par cette API, avec trois thèmes au choix : Natheo-Base, livré sans style, une nouvelle version de Natheo-Horizon et StormFront.

La version apporte aussi des nouveautés dans l'administration.

- Un module de carrousels d'images, avec une légende traduite pour chaque image, à placer dans un bloc de page.
- Une médiathèque revue, avec une recherche, la sélection de plusieurs fichiers et le stockage des médias sur un serveur externe.
- Un éditeur de texte visuel qui enregistre toujours le contenu en Markdown. Il propose une relecture des textes par une IA, désactivée par défaut, et aucune correction n'est appliquée sans votre accord.
- Une administration qui reprend l'identité visuelle de Natheo-Horizon.

Le détail se trouve dans le [journal des modifications](https://github.com/counteraccro/natheo/blob/master/CHANGELOG.md).

## La 2.2

Le chantier suivant consiste à rendre toutes les actions de l'administration disponibles par l'API, avec les mêmes droits. Une application externe pourra alors créer une page, envoyer une image dans la médiathèque ou gérer les utilisateurs sans ouvrir l'administration. La 2.2 doit en être la première étape, avec des ressources d'écriture dans l'API v2 pendant que l'administration actuelle continue de fonctionner. La modification d'une page directement depuis le site public est prévue dans ce chantier.

## Nathéo 3.0

La 3.0 cassera la compatibilité avec les versions précédentes. L'administration sera réécrite comme un client de l'API, au même titre que le site public, et l'API v1 sera supprimée. Elle est dépréciée depuis la 2.1, et ses réponses signalent déjà la v2 aux applications qui l'utilisent encore.

L'avancement se suit sur les [milestones](https://github.com/counteraccro/natheo/milestones) et les [Epics](https://github.com/counteraccro/natheo/issues?q=label%3AEpic) du dépôt. Les idées pour la suite se discutent sur le [Discord](https://discord.gg/CgcMCcbmaR).

## Version 2.1, the latest release

Version 2.1 was split into several projects, each tracked in an Epic on GitHub. All of them are finished.

A published page now has a draft, and the "Page validation" option has contributors' pages reviewed by an administrator before they go live. The API v2, built with API Platform, exposes pages, menus, comments, site options and user sessions. The public site was rewritten to go through this API, with three themes to choose from: Natheo-Base, shipped without styling, a new version of Natheo-Horizon, and StormFront.

The release also brings new features to the administration.

- A carousel module for images, with a translated caption for each image, to place in a page block.
- A reworked media library, with search, multiple file selection and storage of media on an external server.
- A visual text editor that still saves content as Markdown. It offers a review of the texts by an AI, disabled by default, and no correction is applied without your approval.
- An administration that takes on the visual identity of Natheo-Horizon.

The details are in the [changelog](https://github.com/counteraccro/natheo/blob/master/CHANGELOG.md).

## Version 2.2

The next project is to make every action of the administration available through the API, with the same permissions. An external application will then be able to create a page, upload an image to the media library or manage users without opening the administration. Version 2.2 is meant to be the first step, with write resources in the API v2 while the current administration keeps working. Editing a page directly from the public site is part of this project.

## Nathéo 3.0

Version 3.0 will break compatibility with previous versions. The administration will be rewritten as a client of the API, like the public site, and the API v1 will be removed. It has been deprecated since 2.1, and its responses already point the applications still using it to the v2.

Progress can be followed on the [milestones](https://github.com/counteraccro/natheo/milestones) and [Epics](https://github.com/counteraccro/natheo/issues?q=label%3AEpic) of the repository. Ideas for what comes next are discussed on [Discord](https://discord.gg/CgcMCcbmaR).

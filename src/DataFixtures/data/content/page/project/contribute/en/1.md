## Report, suggest, discuss

- A bug or an idea? Open an [issue on GitHub](https://github.com/counteraccro/natheo/issues), from one of the forms.
- A question, want to take part? Join the [Discord](https://discord.gg/CgcMCcbmaR).
- Security vulnerabilities are reported **privately**, following the [security policy](https://github.com/counteraccro/natheo/blob/master/SECURITY.md).

## Contribute to the code

Every topic follows the same path: an issue, a branch, a pull request linked to the issue. Tests (PHPUnit on MySQL and PostgreSQL) and the front-end build run automatically on every pull request. Everything is detailed in the [contribution guide](https://github.com/counteraccro/natheo/blob/master/CONTRIBUTING.md).

## Informar, proponer, conversar

- ¿Un error o una idea? Abre una [issue en GitHub](https://github.com/counteraccro/natheo/issues), desde uno de los formularios.
- ¿Una pregunta, ganas de participar? Únete al [Discord](https://discord.gg/CgcMCcbmaR).
- Un fallo de seguridad se comunica **en privado**, siguiendo la [política de seguridad](https://github.com/counteraccro/natheo/blob/master/SECURITY.md).

## Contribuir al código

Cada tema sigue el mismo camino: una issue, una rama, una pull request vinculada a la issue. Las pruebas (PHPUnit en MySQL y PostgreSQL) y el build del front se lanzan automáticamente en cada pull request. Todo está detallado en la [guía de contribución](https://github.com/counteraccro/natheo/blob/master/CONTRIBUTING.md).

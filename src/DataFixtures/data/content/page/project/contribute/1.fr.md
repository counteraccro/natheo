## Signaler, proposer, discuter

- Un bug ou une idée ? Ouvrez une [issue sur GitHub](https://github.com/counteraccro/natheo/issues), à partir de l'un des formulaires.
- Une question, une envie de participer ? Rejoignez le [Discord](https://discord.gg/CgcMCcbmaR).
- Une faille de sécurité se signale **en privé**, en suivant la [politique de sécurité](https://github.com/counteraccro/natheo/blob/master/SECURITY.md).

## Contribuer au code

Chaque sujet suit le même chemin : une issue, une branche, une pull request liée à l'issue. Les tests (PHPUnit sur MySQL et PostgreSQL) et le build du front sont lancés automatiquement sur chaque pull request. Tout est détaillé dans le [guide de contribution](https://github.com/counteraccro/natheo/blob/master/CONTRIBUTING.md).
